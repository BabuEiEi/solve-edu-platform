## ขั้น 3 — ตรวจทานก่อน merge (Opus)

พบและแก้:
1. **เส้นทางยาวเกินที่ Windows รุ่นเก่ารับได้ (260 ตัวอักษร)** — ชื่อคนยาว + ชื่อไฟล์ยาวรวมกันได้เกิน (จำกัดแค่ 150 ไบต์ต่อส่วน ซึ่งภาษาอังกฤษ = 150 ตัวอักษร) → ลดเหลือ 100 ไบต์ต่อส่วน และ `fitName` ตัดชื่อไฟล์ให้เส้นทางรวม ≤ 200 อักขระ (เก็บนามสกุล) · unit ใช้ชื่อ ASCII ยาว · mutation (ถอด `fitName`) = **FAIL**
2. **ออกจากหน้าระหว่างดาวน์โหลด** — หน้านี้ยังทำงานอยู่ในหน่วยความจำ พอโหลดเสร็จจะ `draw()` ทับหน้าใหม่ที่ผู้ใช้เปิดไปแล้ว และยังบันทึกไฟล์ที่ไม่ได้ขอ → ตรวจ `location.hash` ตอนเริ่ม: เปลี่ยนแล้วหยุดโหลดไฟล์ที่ยังไม่ได้ขอ ไม่สร้าง zip ไม่บันทึก ไม่วาดทับ (รวมกรณีเกิด error หลังออกจากหน้า) · unit: ไฟล์ที่ 5–6 ไม่เคยถูกขอ, หน้าใหม่ไม่ถูกทับ · mutation (ไม่ส่ง `isCancelled`, วาดทับหลัง error) = **FAIL** · (กล่อง Drive เดิมมีปัญหาเดียวกัน แต่ซ่อนอยู่ จึงไม่แก้ในรอบนี้)
3. **ลิงก์ดาวน์โหลดหมดอายุ** — เซ็นลิงก์ทุกไฟล์ไว้ล่วงหน้า 10 นาที ถ้าโหลดช้า ไฟล์ท้ายๆ ได้ 400 → ใช้ค่าเริ่มต้น 1 ชั่วโมง (ลิงก์อยู่ในหน่วยความจำของผู้ตรวจ ใช้ได้เฉพาะ bucket ส่วนตัวนั้น)
4. **ตรวจแล้วไม่พบปัญหา**: ข้อความในสรุป.xlsx ไม่เป็นสูตร (ทดสอบ `=HYPERLINK(...)`) · bucket `task-files` รับเฉพาะเอกสาร (ไม่มี .exe) · ผู้เรียนอื่น/คนนอกไม่ได้งานของคนอื่น (RLS เดิม ทดสอบผ่าน API จริง) · CSP เดิมพอ (`connect-src` มี Supabase)
5. **เทสต์ไม่นิ่งจากเครื่อง sleep** — Mac เข้าโหมด sleep ระหว่างรัน integration และ E2E หลายรอบ (`pmset -g log`) → เทสต์ค้างจนหมดเวลา · รันซ้ำด้วย `caffeinate -dims` ผ่านทุกชุด · ไม่ใช่ปัญหาของโค้ด

## ความเสี่ยงที่ยังเหลือ

- zip ทั้งไฟล์สร้างในหน่วยความจำของเบราว์เซอร์ ทดลองเฉพาะไฟล์เล็ก ยังไม่ได้ลองใกล้ 500 MB บนมือถือจริง — ถ้าพบปัญหาให้ลดเพดาน (`ZIP_MAX_BYTES`)
- ทดลองแตก zip บน macOS เท่านั้น ยังไม่ได้ลอง Windows Explorer (ไฟล์ตั้ง flag UTF-8 ซึ่ง Windows 10 ขึ้นไปรองรับ)
- ไฟล์ zip มีชื่อและงานของผู้เรียนอยู่ในเครื่องผู้ตรวจ — มีข้อความเตือนในหน้า แต่การเก็บรักษาเป็นความรับผิดชอบของผู้ตรวจ (ต่างจาก Drive ที่เก็บไว้ที่เดียว)
- ผู้ตรวจที่ไม่มีไฟล์งานให้โหลดได้ (ไม่มีสิทธิ์/หมดอายุ) จะได้ zip ที่ไม่ครบ พร้อมรายชื่อไฟล์ที่ขาด — ไม่ล้มทั้งชุด
- ถ้ามี dev server ค้างอยู่ก่อนรัน E2E สเปก Drive จะไม่เจอปุ่ม (ต้องปิดก่อน)
