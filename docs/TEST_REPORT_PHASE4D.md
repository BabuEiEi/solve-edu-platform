# Test report — Phase 4d (ห้ามนำแบบทดสอบ/Rubric ที่เก็บถาวรไปใช้ใหม่)

งานค้างจาก Phase 4a: หน้าจอซ่อนปุ่ม "มอบหมาย" และไม่เสนอ Rubric ที่เก็บถาวร แต่ฐานข้อมูลตรวจแค่ "ฉบับเผยแพร่" — เรียก API ตรง หรือเปิดหน้า "มอบหมายให้รุ่น" จากที่อยู่เว็บ ยังมอบหมายแบบทดสอบที่เก็บถาวรได้
