## ขั้น 2 — ข้อเรียงลำดับที่ไม่แตะ = ยังไม่ตอบ

`assessments/items.js`: ใต้รายการมีสถานะ "ยังไม่ได้จัดลำดับ — …" + ปุ่ม "ใช้ลำดับนี้" · ย้ายรายการหรือกดปุ่ม → "จัดลำดับแล้ว" และบันทึกอัตโนมัติ (ส่ง input ครั้งเดียว) · คำตอบที่บันทึกไว้แล้วถือว่าจัดลำดับแล้ว · `logic.js readAnswers` อ่านลำดับเฉพาะเมื่อ `q:<item>:set = 1` · ฝั่ง server ไม่เปลี่ยน (ไม่มี `order` = ไม่ตอบ) → เตือนก่อนส่ง, หมดเวลาได้ 0 ในข้อนั้น, ช่อง "ตอบ" ในผลวิเคราะห์นับถูกต้อง
