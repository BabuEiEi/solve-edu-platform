การตัดสินใจของเจ้าของระบบ (2569-11-08): ลบได้เฉพาะรายการที่ยังไม่มีผู้ใช้ (ที่ใช้แล้วเก็บถาวร) · ลบบัญชี = ลบการเข้าสู่ระบบและข้อมูลส่วนตัว เก็บผลแบบไม่ระบุตัว (ผู้ดูแลระบบเท่านั้น) · "รหัสชื่อผู้ใช้" = รหัสประจำตัว (ไม่ใช้เข้าสู่ระบบ) · สิทธิ์ตามขอบเขตเดิม
