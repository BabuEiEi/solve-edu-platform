พบและแก้ระหว่างทาง (ก่อน commit):
1. **บั๊กสิทธิ์ที่อ่านโค้ดเจอ:** policy ของ `tasks` เขียน `where a.task_id = id` ในคำสั่งย่อย — `id` ผูกกับ `task_allocations.id` ไม่ใช่ `tasks.id` ผู้เรียนจะไม่เห็นภาระงานของตน → แก้และเพิ่ม test (mutation ย้อนบั๊กนี้ → **FAIL** 2 ข้อ)

3. CHECK constraint ที่เรียกฟังก์ชันใน `private` ทำงานด้วยสิทธิ์ผู้เรียก (ไม่มีสิทธิ์) → ย้ายการตรวจลิงก์ไปไว้ใน trigger
