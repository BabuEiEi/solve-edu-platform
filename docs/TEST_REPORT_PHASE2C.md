## ความเสี่ยงคงเหลือ (ขั้น 1–4)

- การเทียบข้อความไทยครอบคลุม ำ/ํา และลำดับวรรณยุกต์กับ ํ เท่านั้น — ลำดับการพิมพ์สระบน/วรรณยุกต์แบบอื่น (เช่น วรรณยุกต์ก่อนสระ ิ) ยังถือว่าต่างกัน; ผู้สร้างใส่คำตอบที่ยอมรับได้หลายแบบได้
- ข้อเรียงลำดับที่ผู้เรียนไม่แตะเลยถือว่าตอบตามลำดับที่เห็น (ไม่นับเป็น "ยังไม่ตอบ")
- ข้อจับคู่ที่ฝั่งขวามีรูปแสดงเป็นการ์ดทุกข้อทางซ้าย — ยาวบนมือถือถ้ามีหลายข้อ
- ยังไม่มีหน้าสร้างข้อสอบกลุ่ม ข (ขั้น 5)
- แก้ไขข้อเรียงลำดับ: ฟอร์มแสดงลำดับที่เก็บ (สลับแล้ว) เพราะเฉลยอ่านกลับไม่ได้ — ถ้าต้องการเปลี่ยนเฉลยต้องเรียงใหม่ทั้งหมดแล้วติ๊ก
- วิธีให้คะแนนอ่านกลับไม่ได้ (อยู่คู่เฉลย) — ฟอร์มแก้ไขแสดงค่าเริ่มต้นเสมอ

- การวิเคราะห์ข้อสอบยังไม่มีสัดส่วนถูกรายช่อง (ขั้น 6)
