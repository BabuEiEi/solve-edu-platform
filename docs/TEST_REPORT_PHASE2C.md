- ข้อจับคู่ที่ฝั่งขวามีรูปแสดงเป็นการ์ดทุกข้อทางซ้าย — ยาวบนมือถือถ้ามีหลายข้อ
- ติดป้ายบนรูป: วางจุดด้วยการแตะ/คลิกเท่านั้น (ปรับละเอียดด้วย X/Y) — ยังไม่มีการลากจุด
- ข้อความในปุ่มเลือกไฟล์เป็นภาษาของเบราว์เซอร์ (เช่น “Choose File”)
- แก้ไขข้อเรียงลำดับ: ฟอร์มแสดงลำดับที่เก็บ (สลับแล้ว) เพราะเฉลยอ่านกลับไม่ได้ — ถ้าต้องการเปลี่ยนเฉลยต้องเรียงใหม่ทั้งหมดแล้วติ๊ก
- วิธีให้คะแนนอ่านกลับไม่ได้ (อยู่คู่เฉลย) — ฟอร์มแก้ไขแสดงค่าเริ่มต้นเสมอ
- ข้อเรียงลำดับที่ไม่แตะถือว่าตอบแล้ว จึงนับใน "ตอบ" ของผลวิเคราะห์รายตำแหน่งด้วย
- pg_cron (ปิดครั้งที่หมดเวลาอัตโนมัติ) ยังไม่ได้ตรวจบน Supabase project จริง — ตรวจหลัง deploy
