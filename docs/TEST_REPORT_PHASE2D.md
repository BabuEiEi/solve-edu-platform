## ขั้น 3 — หน้าจอนำเข้า

ปุ่ม "นำเข้าจากไฟล์ (CSV)" ข้างปุ่มเพิ่มข้อ (เฉพาะฉบับร่าง) → แผง: ขั้นตอน 3 ข้อ, ดาวน์โหลดแม่แบบ, ปุ่มเลือกไฟล์ภาษาไทย → ตัวอย่างทุกข้อ (ลำดับข้อต่อจากที่มี, ประเภท, โจทย์, คะแนน, จำนวนตัวเลือก; ไม่แสดงเฉลย) หรือรายการแถวที่ผิด (สูงสุด 50 รายการ + จำนวนที่เหลือ) · ปุ่มยืนยัน "นำเข้า N ข้อ" มีเฉพาะเมื่อไม่มี error · สำเร็จ → แผงปิด รายการข้อขึ้น "พร้อมเผยแพร่" · server ปฏิเสธ → แผงค้างพร้อมข้อความ "ระบบไม่รับข้อที่ n ในไฟล์ (แถว n+1) … ยังไม่มีข้อใดถูกนำเข้า" · `service.importItems` แปลง `DETAIL "แถวที่ n"` เป็นข้อความนี้ · `filePicker` รับ `none` (ซ่อน "ยังไม่ได้เลือกไฟล์" เมื่อหน้าแสดงชื่อไฟล์ที่อ่านแล้ว)

พบจากภาพหน้าจอ: หลังอ่านไฟล์แผงวาดใหม่ ปุ่มเลือกไฟล์รีเซ็ต แต่ยังเขียน "ยังไม่ได้เลือกไฟล์" ข้างปุ่มทั้งที่ชื่อไฟล์อยู่ด้านล่าง → ซ่อนข้อความนั้นเมื่ออ่านไฟล์แล้ว
