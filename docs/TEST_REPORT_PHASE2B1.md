### E2E ที่เพิ่ม

trainer ตั้งเวลาทำ 15 นาทีผ่านหน้าจอ → ผู้เรียนเห็นตัวจับเวลา → ตอบ 1 ข้อ รอสถานะ "บันทึกแล้ว" (ไม่มีอะไรใน localStorage) → เปิดอีกเครื่องด้วยบัญชีเดิม คำตอบตามไป → ส่ง → trainer กด "+1 ครั้ง" พร้อมเหตุผล → ผู้เรียนเห็น "2 ครั้ง (รวมสิทธิ์เพิ่ม 1)" และเริ่มได้อีก · ไม่มี CSP violation

E2E เดิม "รีเฟรชกลางคันแล้วคำตอบไม่หาย" จับปัญหาจริงได้: เดิมการบันทึกรอ 1.5 วินาที รีเฟรชเร็วจึงหาย → ตัวเลือกบันทึกทันที, ช่องตัวเลขรอหยุดพิมพ์, การเปลี่ยนระหว่างกำลังบันทึกไม่ถูกทิ้ง, สถานะ `data-state="saved"` เมื่อคำตอบบนจอตรงกับบน server
